# ETF历史来源核查

22只ETF已取得回测起点之前的官方产品资料，并完成199份有效概要、1077页的字段核对。结论仅覆盖基金身份、类型、成立及上市日期、资料编制日期、投资范围和业绩比较基准；没有把它们变成历史行业权重，也没有切换模型输入。

协议在提交`414603c5`登记。活跃数据仍为`2026-11-20-industry-dated`，策略、8%预警、不恢复风险、换手政策、历史收益和11月23日纸面计划保持原样。本阶段没有重新拟合或新增前向观察。

## 保留的失败与裁定

- 医疗ETF的2023年12月20日上交所概要链接实际返回107页招募说明书，身份核验拒绝该文件。基金管理人同日概要另行取得；两个原文件及首次失败日志均保留。
- 管理人概要的PDF页树声明4页，实际有5个叶页，最后一页为原文件自带的软件试用提示。审阅副本保留全部5页，逐页内容流和两种解析器文本一致；原文件未改，结构缺陷未宣称消失。
- 两份概要的基准行处在页末，原提取范围带入了下一页的页脚`2`和`2/6`。原提取未覆盖；核实结果只按已检查的页面边界去掉这两个页脚。
- 十份概要将成立日和上市日放在相邻单元格。首次提取因出现两个日期而拒绝；后续按明确的“上市日期”标签取值，两种解析器全文上下文一致，并逐一检查原表。
- 初始标题筛查漏了“份额合并”这个表达；另行对全部目录补筛并取得两份合并公告，没有把未命中当作不存在公司行为的证明。

## 对策略的影响与后续条件

来源补充范围限于原始材料和审查产物。运行包、配置、活跃数据、模型、账本和冻结纸面计划均按原哈希核对；本地375项测试通过，1项主机符号链接测试跳过。原历史回测收益不变，也没有新增收益优势。

ETF尚不能与股票直接共用CAPCO行业上限。后续[持仓核查](etf_holdings.md)已取得528份定期报告并完成目标表格字段复核，报告期末与公开日期分列。披露可用日约定、基金行业口径与CAPCO映射、现金、衍生品和未匹配部分的处理仍待完成。遗漏权重不能填零，季度披露也不能当成每天真实持仓。

接入前分别登记类型/指数身份更换与行业穿透权重的对照，保留同风险动量基准、既有候选预算和采用门槛；通过旧输入一致性、完整重训、独立核账及纸面账户验证后才可启用。历史股票池选择偏差、精确发布时间、其他状态缺口及真实前向验证继续保留。
