## E4：核心数据契约与共享执行边界

主要改动：`models.py`、`allocation.py`、`simulation.py`、`planning.py`、`accounts.py`、`ledger.py`。仅在需要共享执行职责时新增 `execution.py`。

- 优先定义预测、开盘报价、目标权重、账户快照和成交结果的字段、单位及时间语义。类型放在负责该数据的模块；先用 `TypedDict`描述现有字典，只有确需行为或生命周期时才使用数据类。
- 价格和金额用元，记账现金用整数分，数量用整数股，权重与收益为比例；单位转换限定在明确边界。保留既有JSON字段、空值语义、数组类型和键顺序。
- 将跨模块使用的 `_Execution`整理成公开共享执行器，回测和纸面交易各负责准备输入，共用同一成交语义。独立核账仍保留自己的计算。
- 将 `allocate`的参数按已有业务关系明确为账户、预测、市场约束和政策输入；只合并确实共同传递的状态，不为缩短签名单建转发层。
- 从账户携带并校验原始本金，解释当前100万元约束的归属；不在工程阶段扩展任意本金研究，也不改变历史分母。
- 已持久化对象保持原导入路径和可加载性，不能靠重存joblib替代兼容。

验收：核心调用方不再跨模块引用私有执行器；金融边界类型检查通过，旧模型和JSON正常读取，全部历史与纸面结果精确一致。若类型转换改变舍入、字段顺序或计算顺序，退回该改动。

## E6：按产物依赖校验和检索

主要改动：`dataset.py`、`storage.py`及相关训练、评估、计划入口；确需独立职责时新增 `integrity.py`。

- 为新运行记录必需的数据、配置、模型、源码与父产物依赖闭包。已有完整性清单和旧证据原封保留，新记录通过新格式登记；未知格式和不完整闭包必须拒绝。
- 日常读取验证当前产物及其完整依赖，发布仍执行全库检查。不能仅凭路径、大小或修改时间代替内容哈希；只能在同一运行内安全复用已经验证的内容。
- 源码兼容按实际依赖定义，覆盖动态导入、共享交易规则和序列化实现；相关代码变化仍需精确回归。新旧兼容记录并存，不能修改旧记录使其自动适配新代码。
- 建立从现有运行记录生成的实验索引，显示父输入、候选范围、成本、状态、输出及有效配置。索引可重建，实际采纳仍只由登记配置决定，不按最高收益自动切换。
- 旧失败及不活跃实验可查但不混入当前结论；新回归复用标准实现，通常只新增参数、结果和日志，不再复制一套检查源码。

验收：修改依赖内文件会拒绝载入，删除依赖或伪造兼容证据会失败；无关报告代码变化不会使不依赖它的金融产物失效；全库检查仍能发现历史档案被改动。对漏登记、路径越界、循环依赖和运行中输入变化有明确测试。

## 研究阶段：保持暂停

工程E0–E7完成后也不会自动启动以下阶段。其细项与来源范围沿用[研究待办](remediation.md)，必须在明确恢复研究后按先后依赖执行。

| 阶段 | 范围 | 前置条件及验收 |
| --- | --- | --- |
| R1 | 历史股票池、公告发布时间、行情状态、公司行为和ETF敞口 | 按事前范围逐项补证；未知与冲突可追踪。影响结论的缺项须解决，或事前限定并明确排除研究范围，不按收益选择处理方式 |
| R2 | 比赛费用、撮合及容量模型 | 白皮书与后续官方确认文本明确；数据能支持所选粒度。新执行模型另立实验，不替换冻结的开盘代理结果；对价格、数量和费用分别校验 |
| R3 | 独立收益检验 | R1、R2达到已声明范围要求，并有新增合格样本或另行登记的新范围。固定候选、基准、成本、统计门槛和停止规则后才运行；现有六项单独改动和两项组合预算保持耗尽 |
| R4 | 前向纸面观察 | R3满足采用条件或明确登记为基准观察；使用实际发生且可核验的行情、冻结意向和账户。没有报价就记录未执行，不回填成交，不续用过期计划 |

数据修正、策略研究和工程等价迁移使用不同运行范围。收益检验须同时报告净收益、回撤、换手、成本、分段表现和相对同风控动量结果；未通过就保留基准或不采用，并报告失败。公开来源、比赛口径和未来样本的到达时间未知，不给R1–R4虚构固定完成日期。

## 提交、失败与回退

每个工程阶段按“实现 → 检查 → 必需的完整回归 → 全库完整性 → 提交 → 普通推送 → 实际CI结果 → 独立远端字节核对”完成。文档或锁文件变更按其影响选择检查，不因修改文档重新训练。

发生差异时先定位输入、计算、序列化或环境原因。金融结果不同的改动不能作为等价重构发布；确属研究修正则单独登记并等待研究恢复。已经发布的变更用后续修复或revert处理，不强推、不清除失败记录、不覆盖旧输出。

优先从E0、E1开始，先让后续重构拥有统一的验证工具，再逐步调整核心结构。实施进度更新本表；当前有效研究结论仍以[项目状态](status.md)为准。
