# 卖出预算与退出约束

纸面流程测试发现：当选股或仓位约束要求卖出超过普通预算时，原线性规划无解，
后备逻辑只按总仓位上限缩减，可能继续持有已经不在候选池的证券。
本研究按[独立协议](../configs/protocols/exit_budget_repair.json)只检验一个确定性修正，
不扩展此前六项改动、两项组合的候选预算。

## 已观察的问题

对当前主策略75个历史账户逐日复现，完整账本均一致。捕获22次无解，10/20/30bp
分别为17/4/1次；其中10bp连续账户9次，其他连续账户没有出现。移除单一卖出预算
约束后，22次均可行；满足其余约束的最低卖出量为净值的51.58%—82.47%，超过50%预算。

[诊断记录](../artifacts/checks/optimizer_diagnosis_2026-11-20/diagnosis.json)保存每次持仓、
候选、原目标和完整线性规划矩阵。它只解释既有失败，未计算修正后的收益。
诊断及其对应市场结果已经被研究，后续比较不是独立样本。

22次中20次涉及仍有正预测边际的被剔除持仓，不能统一解释为预测收益转负。
按保存矩阵独立求解，最低预算修正后22次全部可行，等式、边界和不等式最大违约为零，
见[约束复核](../artifacts/checks/optimizer_diagnosis_2026-11-20/constraint_review.json)。
这证明约束冲突可解，不证明新增换手能够改善收益。

保存的每个问题均可直接交给SciPy复现；例如在项目根目录运行以下Python代码，
`original.status`应为2，`minimum.success`应为真：

```python
import json
from scipy.optimize import linprog

with open("artifacts/checks/optimizer_diagnosis_2026-11-20/diagnosis.json", encoding="utf-8") as f:
    problem = json.load(f)["cases"][0]["problem"]
original = linprog(**problem)
minimum = linprog(**{
    **problem, "c": problem["A_ub"][-1],
    "A_ub": problem["A_ub"][:-1], "b_ub": problem["b_ub"][:-1],
})
```

## 唯一修正

先求解原问题。仅当求解器报告约束无解、且存在卖出预算时，移除这一条约束，
以总卖出量最小为目标重新求解。其余约束可行时，只将卖出预算提高至最低必要量加
`1e-9`权重的数值余量，再使用原经济目标求解。买入预算、现金、单只和行业上限、
总仓位、可卖数量及流动性限制均保留；实际费用没有新增或减免。

超时、无界或求解器异常不能作为放宽依据。状态含义依据
[SciPy HiGHS文档](https://docs.scipy.org/doc/scipy-1.15.2/reference/optimize.linprog-highs.html)。
如果锁定持仓等硬约束仍使问题无解，继续记录无法完成的减仓，不把不可卖股数视为成交。
8%永久退出沿用原路径，原始净值高水位和不恢复机制不变。

两组各重新拟合48个模型。原规则组须保持模型、预测、选型及1425个账户完全一致；
修正组在内层验证和外层评估使用同一修正，并与采用相同修正的动量比较。
固定旧预测和旧选型的对照另存，区分规则直接影响与重新选型影响。
所有账户都核对现金、费用、股数和执行时点；不根据外层收益继续调整修正参数。

只有工程条件通过、三档连续净收益均不低于原策略且观察到的最大回撤均不超过8%，
才允许启用。历史条件通过也不构成独立收益优势；不通过则保留现有策略，并完整报告。
## 完成结果与决定

两组共完成96次拟合与重载校验。每组48个模型、12组完整预测数组均与原模型一致，
11个外层窗口和最新一期的选择也未变化。原规则1425个账户完整摘要和账本精确一致；
修正组150个账户与固定旧预测的150个账户也精确一致。共评估1725个账户。

| 每边滑点，另计交易费 | 原连续净收益 | 修正后连续净收益 | 修正后最大回撤 | 原10日均值 | 修正后10日均值 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 10bp | 31.03% | 7.31% | -8.12% | 2.12% | 1.62% |
| 20bp | 7.88% | 7.88% | -6.40% | 1.05% | 0.70% |
| 30bp | 3.56% | 3.56% | -6.94% | 1.12% | 0.63% |

区间为2025-11-18至2026-11-02，数据截止2026-11-19。10日均值取23个完整、重置本金
的账户。修正后仍与采用同一修正的动量基准持平，三档10日均值均下降。
10bp连续收益下降且回撤超出8%验收条件，因此**不启用修正，活跃换手政策保留`legacy`**。
这不是新的收益优势，也没有根据结果继续搜索参数。

10bp连续路径首次在2025-12-16发生经济差异，最低预算修正实际触发两次。
修正账户于2026-01-19和01-20先后进入45%和20%仓位阶段，7月21日进入永久退出；
原账户分别于2月3日和6月4日降级，期间未永久退出。原始净值高水位始终保留。

修正账户交易数从167降至84，最终交易费与滑点合计由29,383.16元降至14,488.88元。
期末财富少237,193.18元；按账务恒等式，变化后路径的成本前收益少252,087.46元，
费用少14,894.28元。因此不能把收益下降简单归为总手续费增加。持仓、风险触发及随后
的参与程度一起变化，该分解不是对各因素独立收益的估计。
