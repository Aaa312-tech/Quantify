# 行业分类时点对照

本页记录股票行业接入阶段；后续活跃输入见[ETF接入](etf_integration.md)。日期化股票分类继续使用；这项决定依据事前登记的数据和核账条件，不按收益方向选择。它不证明策略超过同风控动量，也不增加前向样本。

20bp下的下降全部发生在覆盖过滤后的重训、校准阶段。首笔变化出现在2026年1月26日：
半导体ETF卖出数量由21200份变为79200份；此后首次降至45%风险仓位的日期从3月4日
提前到2月3日。模型和规则选择没有改变，这是仓位路径对输入样本变化敏感的证据，
不能据此单独估计某一校准参数的贡献。明细见[经济路径核对](../artifacts/checks/industry_timing_2026-11-21/economic_review.json)。

30bp下日期化组最大收盘回撤为8.23%，发生于2026年6月8日，超过8%预警线。
预警使用已观察净值，不能保证价格变动后的实际损失被限制在8%以内；收益较高也不表示
这一成本档更优。日期化与静态对照的1425个账户净收益均相同，但140个完整账本记录有变化。

## 验证与结果边界

- 三组各414612行分类与4560732项行业排名通过独立来源连接和显式排序核对，未来分类扰动不改变此前数据。
- 旧输入48个模型重载预测一致、1425个完整账户一致、75个纸面账户一致；补齐独立核账的源码依赖后再次验证全部75个纸面账户。
- 每组48次拟合与重载、1425个重训账户、1425个固定预测账户、75个纸面账户；所有原采用条件保留。
- 本地375项测试通过，1项主机符号链接检查跳过。历史ST审查分别绑定三个新快照；已核验区间没有进入训练或买入。

新纸面核验发现并修正了缺失开盘报价被构造成空价格行的问题。原失败记录保留，
历史成交器与全部训练依赖不变；最终源码下另行重放新旧共300个纸面账户，完整账本一致。
修正范围、源码比较及各阶段身份见[纸面修正验收](../artifacts/checks/industry_timing_2026-11-21/paper_missing_quote/closure.json)。

持仓重分类的集中度审查将上一收盘持仓按新旧分组重新汇总，以固定价格隔离分类影响；该诊断不冒充真实开盘敞口。每笔新买入另按开盘价格独立核对30%行业上限。
