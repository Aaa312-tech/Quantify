# 数据契约

## 跳空特征的数值口径

跳空因子在已收盘日计算为`(O_t / C_prev) * (M_t + D_t / C_t) - 1`。
`C_prev`是前一条实际报价的收盘价，`M_t`、`D_t`是映射到当前报价的送转股倍数和每原持股现金。
这与累计总回报指数上的开盘/前收盘比值代数等价，先消去累计缩放可避免它污染后续零跳空的排名。
沿用float64计算、float32入表和平均并列排名，不增加零值阈值。
二进制浮点的表示误差见[Python说明](https://docs.python.org/3/tutorial/floatingpoint.html)，
平均并列排名见[pandas接口](https://pandas.pydata.org/pandas-docs/stable/reference/api/pandas.api.typing.DataFrameGroupBy.rank.html)。

除权日的现金项仍使用当日收盘价，因此这是已完成交易日的信号，不能用作当日开盘成交参考。
缺失报价期间的多项事件按时间顺序合并到下一条实际报价，现金按各事件时的股数累计；
不填补缺失K线、成交能力或收盘估值。实现和全量差异按
[精度修正协议](../configs/protocols/gap_precision.json)单独验收。

## 分红字段的来源范围

`distribution_review`记录每项已核验字段、来源文件哈希、证据页码、核验方法和保守可用时间。
`LABELLED_PRIMARY_AND_STRUCTURED`表示受支持版式的机器逐字段核验，
`MANUAL_PRIMARY_REVIEW`表示已有全文与相关页面图像核验；两者均不认证未列明的条款。
原始`date_status`保留其原来源含义，新增核验范围由`distribution_review.fields`明确列出。
`id`是原记录的固定索引，`description`保留原来源描述；修正后的权益以数值字段及其核验
记录为准，不能从索引或旧描述重新解析现金金额。

全量核验不依赖持仓、预测或收益。自动处理要求单一实施公告、明确日期角色、实施方案税前
金额及独立来源一致；未支持的版式、修订、多重匹配和冲突另列，不把显示精度接近视为通过。
目录日期后的零点仅为回顾研究的保守可用时间约定，不宣称掌握当时盘中发布时间。

`cash_pay_date`是公告支付日，`cash_available_date`是其后第一个已观察开盘。已知支付日
不证明送转股可卖；缺少独立上市依据时`share_list_date`继续为空。`cash_rounding`缺省保留
历史四舍五入，明确的`FLOOR_TO_CENT`先汇总全部应计股数再舍去不足一分部分，随后沿用既有
税额保留情景。每十股分红比例的舍尾不等同于账户现金舍尾，连续收益标签不按账户分位处理。

日期补充使用追加的`distribution_date_reviews`，不覆盖原`distribution_review`或经济条款。
每次补充绑定来源审查所用快照、当时的事件、当前事件及独立验收哈希；已有日期冲突时拒绝
写入。原来源的`date_status`不因新增字段而改写。支付日仍须转换为其后首个已观察开盘，
不能把除息日或股份上市日代作现金可用日。

股份上市日可能恢复原本因公司行为未知而被屏蔽的标签。此次
[日期补充协议](../configs/protocols/distribution_availability.json)只允许独立清单中的106项
标签变化：1/3/5日分别12/36/58项。生成器照常重建全部标签，再逐格对照父表和这份清单；
没有相应证据的协议仍要求全部标签不变。所有非标签输入和其他标签必须精确一致。
5日有效样本的恢复还会改变同行参考收益、训练目标和归一化权重，因此必须重新训练，
不能因特征相同就沿用旧模型。完整来源和失败记录见[接入说明](distribution_availability.md)。

`configs/project.toml`声明活跃快照`bundle`、冻结核验快照`reference_bundle`、研究评估`evaluation`及完整性清单；实际路径以该配置为准。各快照保留登记协议、输入来源和逐字段差异，切换前必须成套验收数据、训练与账户。父快照及历次修正均保留；载入前检查SHA-256及各自截止日期。joblib仅用于本地受信任的快照和模型。

## 已核验停复牌的参考价

`opening_status`按交易日及证券保存公告可用时间与停牌状态。复牌记录可额外保存
`reference_date`和`suspension_evidence`；仅在覆盖日历中全部中间交易日、每条证据在相应
开盘前已公开、最后实际收盘与参考日一致、期间无待另审除权事件时，允许卖出使用该参考。
新买入仍须有前一交易日报价。涨跌停与价格刻度规则不变；流动性和估值检查单独执行。

高乐股份的专项审查用发行人公告确认停复牌事实，用报社页面显示时间的下一分钟作为保守
公开时间上界。它是对存档页面的回溯推断，不是交易所发布回执，也不认证全市场历史状态。
已确认停牌不能消除延用旧收盘估值的不确定性。来源、边界和原失败诊断见
`configs/protocols/resumption_reference.json`及其绑定审查。

## 日期化行业输入

`configs/protocols/industry_timing.json`固定三组对照，不能按收益选择分类口径或可用时间：

| 对照 | 股票分组 | 作用 |
| --- | --- | --- |
| `coverage` | 原静态标签，仅保留当期有来源覆盖的样本 | 衡量缺失过滤及其后续影响 |
| `static` | 最新归档表的大类标签，使用同一历史覆盖掩码 | 回溯归因，禁止启用为策略 |
| `dated` | 当前日期之前最新归档表的大类标签 | 按登记日期约定的研究输入 |

股票元数据新增`industry_history`，原字段保留。每条记录包含带时区的`available_at`、
目录日期、分组、覆盖来源和分类来源；分组键为`capco:<门类><两位大类代码>`。
可用日为目录日期后的首个已观察交易日，时刻为上海时间00:00。连续休市期间多期发布
在同一首个交易日生效时使用较晚一期；原来源仍全部保留。此约定不认证真实历史发布时间。

首期之前或新表缺少该股票时，分组为未知；在排名、市场宽度、标签、校准、训练和预测
之前排除对应资格行，不前填未来表、不继承旧类别。最新静态对照若缺少任何历史已覆盖
股票的分类，直接停止，不能另加依赖未来完整性的资格条件。三组均使用同一245行过滤。

信号特征和目标分配读取当日16:00可用分类；实际开盘限制读取执行日09:25可用分类。
若已有持仓在该边界失去分类，账户核算明确失败，不虚构清仓。重分类本身不触发额外调仓，
每笔新买入仍检查当时分组下的30%行业上限。既有持仓的被动集中变化单独记录。

22只ETF保留原主题标签，三组都不将其强行映射到上市公司分类。股票CAPCO键与ETF标签
分开，因此原来同名股票和ETF不再自动合并；`coverage → static`的变化同时包含分类体系、
粒度和这种组合约束变化，不能称为纯粹的时间修正或选股收益。ETF的经济行业风险与历史
标签可用性仍未认证。
