# 策略方法

## 信号与选型

基准是同输入、同风险约束的动量策略。模型在动量候选池内学习同行业留一残差收益的横截面排序；候选为Ridge和直方图梯度提升树，分别检验25%和50%的混合权重。行业检验包含样本覆盖、残差Rank IC、分组差异和跨块稳定性。

信号使用已完成的收盘数据，在下一交易日开盘尝试成交。预测目标为5日收益；次日计划表示执行日期，不是1日收益模型。选型只读取过去验证段，当前采用条件为 `positive_score`。

换手研究把保留排名、替换数量、排名差、正常与谨慎状态预算、惩罚和再平衡缓冲拆开比较。主策略使用 `legacy`；全部16个规则对照及注册研究见[策略对照](strategy_study.md)。

## 仓位与风险

初始资金100万元，通常每5个账户交易日再平衡，风险变化可提前触发。

| 风险阶段 | 总仓位上限 | 行为 |
| --- | ---: | --- |
| 正常 | 90% | 按信号调仓 |
| 回撤达到4% | 45% | 降低仓位 |
| 回撤达到6% | 20% | 停止买入 |
| 回撤达到8% | 0% | 在可交易时点退出 |

风险沿用原净值高水位，降级后不自动恢复。市场状态还可能降低仓位上限。目标单股14%、行业28%，实际买入后再检查15%和30%上限；强制降风险的卖出优先于普通换手限制。8%是预警及退出目标，停牌、跳空或涨跌停可能使实际回撤超过它。

## 时间与成本

训练252个交易日，间隔6日，验证63日，再间隔6日，测试21日。按标签的实际退出日期净化样本，避免跨边界使用未来收益。当前有11个外层窗口，另有截止日拟合，后者不进入历史外层测试。

执行以有效开盘报价为代理，模拟整数股、T+1、方向涨跌停、前一交易日流动性、跳空限制、佣金、最低佣金、过户费和印花税。滑点按10/20/30bp每边单独扣除现金，不同时偏移成交价。各档独立计算订单与风险路径，净收益不必随成本单调变化；日线不能证明真实竞价队列可成交。

现金分红在支付日之后首个已知开盘才可使用，到账前保留应收价值。送转股等待已核验上市日。实际股东权益与除权参考参数分别使用，未知日期不以除息日替代；账户舍入及零股限制见[数据契约](data_contract.md)。

## 评估与结论

外层评估包含23个完整10日账户、1个尾部账户及231日连续账户。10日账户每期重置本金，其平均收益不能连乘成连续账户收益。成对区间采用固定随机种子、长度2的循环块抽样；历史重放不是独立市场试验。

当前11个外层窗口与截止日均选择动量及基准换手规则。10/20/30bp下连续净收益为35.93%/3.38%/11.79%，与同风控动量相等，未建立模型收益优势。六项单独改动和两项组合的研究预算已用完；没有新增前向收益证据。

594只证券的股票池存在生存者和选样偏差。日期化行业与基金披露按登记的历史可用性约定使用，真实发布时间及每日完整经济敞口未获认证。历史区间已被多轮研究使用；公司行为、历史状态与比赛撮合仍有未解决事项，见[当前状态](status.md)。
